계정 연동 · 자동 로그인

각 업무 시스템의 로그인 계정을 연동해 두면, 시스템 접속이 빨라집니다.
💡
지금: 시스템별 로그인 아이디를 저장해 두면, 타일 클릭 시 아이디를 복사해 바로 붙여넣을 수 있습니다.
향후 (SSO 연계): 회사 인증 서버(SSO/IdP) 또는 포탈 백엔드가 준비되면, 포탈 로그인 한 번으로 각 시스템에 완전 자동 로그인됩니다. 브라우저만으로 동작하는 현재 단계에서는 보안상 비밀번호 자동입력이 제한됩니다.

🛡️ 사용자 관리

가입 승인과 사용자 권한을 관리합니다. (관리자 전용)
💡
승인 절차: 신규 가입자는 승인 대기 상태로 등록되며, 관리자가 승인해야 포탈에 로그인할 수 있습니다.
참고: 현재는 백엔드 없이 이 브라우저에 저장되므로, 실제 여러 PC에서의 승인 연동은 회사 SSO/포탈 서버 도입 시 완성됩니다.
